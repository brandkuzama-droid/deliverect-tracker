# متابعة ربط ديليفركت

منصة لمتابعة ربط فروع **شاهان** و**ميسور** و**شهرزاد** مع تطبيقات التوصيل (جاهز، هنقرستيشن، كيتا، نينجا، ذا شيفز) عبر ديليفركت.

## الملفات

- `index.html` — كود الصفحة كامل (تصميم + منطق) في ملف واحد.

## ملاحظات

- الصفحة الأساسية شغّالة كـ Artifact على Claude، وهي اللي تحفظ البيانات وتحدّثها مباشرة لكل من يفتحها.
- **البيانات نفسها (أرقام الفروع، الـ SN، الإيميلات وكلمات السر) غير محفوظة في هذا المستودع.** هي في قاعدة بيانات المنصة على Claude فقط.
- لو فتحت `index.html` خارج Claude (مثل GitHub Pages)، تشتغل الصفحة بوضع العرض فقط بدون بيانات أو حفظ.

## تعديل الفروع أو التطبيقات

داخل `index.html`:
- `BRANDS` — البراندات
- `BRANCHES` — الفروع (كل فرع مرتبط ببراند)
- `APPS` — تطبيقات التوصيل
- `STEPS` — خطوات الربط
