# متابعة ربط ديليفركت

منصة لمتابعة ربط فروع **شاهان** و**ميسور** و**شهرزاد** مع تطبيقات التوصيل (جاهز، هنقرستيشن، كيتا، نينجا، ذا شيفز) عبر ديليفركت.

## طريقة العمل

- الصفحة كلها في ملف واحد: `index.html`.
- البيانات محفوظة في **JSONBin** (مو في هذا المستودع).
- أول مرة تفتح الصفحة: اضغط **⚙ الإعدادات** وأدخل:
  - **المفتاح** (Master Key أو Access Key من JSONBin)
  - **Bin ID**: أو اضغط "إنشاء Bin جديد" إذا ما عندك واحد
  - **اسمك**: يظهر في سجل التحديثات
- المفتاح يتحفظ في متصفحك فقط، وما ينرفع على GitHub.
- الصفحة تحدّث البيانات كل دقيقتين وهي مفتوحة، ولما ترجع لها. وفيه زر **↻ تحديث** للتحديث اليدوي.

## نقل البيانات

من الإعدادات: **استيراد ملف** (JSON) و**تصدير نسخة**.

## أمان

البيانات فيها إيميلات وكلمات سر. خلّ الـ Bin خاص (Private)، ولا تحط المفتاح في الكود أبداً.

## تعديل الفروع أو التطبيقات

داخل `index.html`:
- `BRANDS`: البراندات
- `BRANCHES`: الفروع
- `APPS`: تطبيقات التوصيل
- `STEPS`: خطوات الربط
