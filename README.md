# متابعة ربط ديليفركت

منصة لمتابعة ربط فروع **شاهان** و**ميسور** و**شهرزاد** مع تطبيقات التوصيل (جاهز، هنقرستيشن، كيتا، نينجا، ذا شيفز) عبر ديليفركت.

## طريقة العمل

- الصفحة كلها في ملف واحد: `index.html`.
- البيانات في **JSONBin** على Binين:
  - **Bin عام:** الحالات والخطوات وأرقام الفروع والملاحظات. أي أحد معه الرابط يشوفه بدون دخول. رقمه مثبّت في `PUBLIC_BIN` داخل `index.html`.
  - **Bin خاص:** الإيميلات وكلمات السر فقط. يظهر للمحرر بس بالـ Master Key.
- **المحرر:** يضغط **🔒 دخول المحرر** ويدخل الـ Master Key مرة وحدة، والمفتاح يتحفظ في متصفحه فقط.
- الصفحة تحدّث نفسها كل دقيقتين، وفيه زر **↻ تحديث**.

## أمان

لا تحط كلمات سر أو إيميلات في الملاحظات، لأن الملاحظات في الـ Bin العام. استخدم قسم **بيانات الدخول** في نافذة الخانة.

## تعديل الفروع أو التطبيقات

داخل `index.html`:
- `BRANDS`: البراندات
- `BRANCHES`: الفروع
- `APPS`: تطبيقات التوصيل
- `STEPS`: خطوات الربط
